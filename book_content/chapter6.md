# الفصل 6: الخلاصة

## ملخص المهارات

| المجال | المهارات | الأوامر |
|--------|---------|---------|
| الأساسيات | استخراج، تصفية | SELECT, WHERE, ORDER BY |
| التجميع | إحصاءات، مجموعات | COUNT, AVG, GROUP BY, HAVING |
| الربط | جداول متعددة | INNER JOIN, LEFT JOIN |
| المتقدم | CTEs, شروط، ترتيب | WITH, CASE WHEN, ROW_NUMBER() |
| الأداء | تحسين البحث | CREATE INDEX |

## الخطوات القادمة

1. **تدرّب** على SQLite أو PostgreSQL
2. **ركّب** التقنيات — CTE + JOIN
3. **حلّل** بياناتك الحقيقية
4. **شارك** نتائجك
