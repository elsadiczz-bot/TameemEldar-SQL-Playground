# الفصل 1: مقدمة

## 1.1 ما هو SQL؟

**SQL** = **Structured Query Language**

**الترجمة:** لغة الاستعلامات المنظمة.

**التعريف:**
> SQL هي اللغة المعيارية للتعامل مع قواعد البيانات العلائقية.

**تشبيه الخزنة:**
- **قاعدة البيانات** = خزنة كبيرة
- **SQL** = المفتاح
- **بدون SQL** = لا يمكنك الوصول
